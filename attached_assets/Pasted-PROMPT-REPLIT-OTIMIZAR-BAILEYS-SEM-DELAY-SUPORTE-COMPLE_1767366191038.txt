8) ROTAS PARA ENVIAR MENSAGEM E MÍDIA
- POST /api/messages/send
  payload:
  {
    chatId,
    type: "text" | "image" | "document" | "audio",
    text?: string,
    mediaUrl?: string,
    fileName?: string,
    mimetype?: string,
    ptt?: boolean
  }
- Regras:
  - type=text: sock.sendMessage(chatId, { text })
  - type=image: sock.sendMessage(chatId, { image: { url: mediaUrl }, caption: text || "" })
  - type=document: sock.sendMessage(chatId, { document: { url: mediaUrl }, mimetype, fileName })
  - type=audio: sock.sendMessage(chatId, { audio: { url: mediaUrl }, mimetype: mimetype || "audio/ogg; codecs=opus", ptt: !!ptt })
- Após enviar:
  - registrar no DB como outbound imediatamente (status: “sending”)
  - emitir pro front “optimistic message”
  - depois atualizar com receipts/updates
