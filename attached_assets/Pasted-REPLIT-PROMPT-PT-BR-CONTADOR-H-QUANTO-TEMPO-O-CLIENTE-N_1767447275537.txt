REPLIT PROMPT (PT-BR) — CONTADOR “HÁ QUANTO TEMPO O CLIENTE NÃO MANDA MSG” + FILTRO POR INATIVIDADE (CRM WHATSAPP / BAILEYS)

OBJETIVO:
Na tela de Contatos, quero:
1) Um contador em PT-BR mostrando há quanto tempo o CLIENTE não manda mensagem (para follow-up / positivar venda)
2) Um filtro para segmentar contatos pelo tempo sem mensagem do cliente

IMPORTANTE:
“Inatividade do cliente” = tempo desde a ÚLTIMA MENSAGEM RECEBIDA do cliente (fromMe=false)
NÃO usar última mensagem enviada por nós (fromMe=true) para esse cálculo.

================================================
A) CAMPOS NO BANCO (POR CONVERSA/CONTATO)
================================================
Manter atualizado SEMPRE:
- lastInboundAt (datetime)  // última mensagem recebida do cliente
- lastOutboundAt (datetime) // última mensagem enviada por nós (opcional)
- lastMessageAt (datetime)  // última mensagem geral (já deve existir)

Regras:
- Se msg.fromMe === false → lastInboundAt = timestamp da msg
- Se msg.fromMe === true  → lastOutboundAt = timestamp da msg
- Sempre → lastMessageAt = timestamp da msg

OBS: isso tem que funcionar mesmo com chats não abertos e contatos desconhecidos.

================================================
B) API — LISTAR CONTATOS COM INATIVIDADE
================================================
No endpoint de listar contatos (ex: GET /api/contacts), retornar também:
- lastInboundAt
- inactiveMs = now - lastInboundAt (ou inactiveDays)
- (opcional) lastOutboundAt

Se lastInboundAt for null:
- marcar como “Nunca enviou mensagem” (cliente nunca respondeu)

================================================
C) FILTRO POR INATIVIDADE (BACKEND)
================================================
Adicionar filtros via query params:
- inactiveMinDays
- inactiveMaxDays
Ex:
GET /api/contacts?inactiveMinDays=7&inactiveMaxDays=30

E também presets fáceis (dropdown):
GET /api/contacts?inactivePreset=8_15
Presets:
- 0_1
- 2_3
- 4_7
- 8_15
- 16_30
- 30_plus
- never_inbound

Regras:
- 30_plus = inactiveMinDays=30
- never_inbound = lastInboundAt IS NULL

================================================
D) FRONTEND — FORMATAÇÃO BONITA EM PT-BR
================================================
Criar função no frontend:

formatTimeAgo(lastInboundAt) => string

Regras de exibição (PT-BR):
- Se lastInboundAt for null → "Nunca enviou mensagem"
- Se < 60 segundos → "agora"
- Se < 60 minutos → "há X min"
- Se < 24 horas → "há X h" (arredondar pra baixo)
- Se < 7 dias → "há X dias"
- Se >= 7 dias → "há X dias" (ou "há X semanas" opcional)

Exemplos:
- 45s → "agora"
- 5min → "há 5 min"
- 2h → "há 2 h"
- 1d → "há 1 dia"
- 10d → "há 10 dias"

ATUALIZAÇÃO AO VIVO:
- Atualizar o texto do contador a cada 60s com setInterval
- NÃO precisa refazer request na API só pra atualizar contador

================================================
E) UI — ONDE MOSTRAR
================================================
Na lista de contatos, abaixo do nome/telefone, mostrar:
"Sem msg: há 2 dias"
ou
"Sem msg: há 3 h"
ou
"Sem msg: agora"
ou
"Sem msg: Nunca enviou mensagem"

Opcional (só front):
- Destaque por cor:
  - até 2 dias: ok
  - 3–7 dias: atenção
  - 8+ dias: crítico
(NÃO precisa mexer no backend pra isso)

================================================
F) PERFORMANCE (OBRIGATÓRIO)
================================================
- NÃO recalcular lastInboundAt varrendo histórico toda vez
- lastInboundAt tem que ser atualizado no momento que salva a mensagem
- A listagem só lê os campos prontos

================================================
G) TESTE DE ACEITE
================================================
1) Cliente manda mensagem agora:
- lastInboundAt atualiza
- contador vira “agora”
2) Depois de 10 min:
- contador vira “há 10 min”
3) Filtro 8–15 dias:
- retorna somente contatos com lastInboundAt entre 8 e 15 dias atrás
4) Contatos que nunca mandaram msg:
- aparecem em “Nunca enviou mensagem”
