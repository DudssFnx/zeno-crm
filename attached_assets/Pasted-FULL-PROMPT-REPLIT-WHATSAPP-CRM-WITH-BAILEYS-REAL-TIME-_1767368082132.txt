A) CONTACT PROFILE PICTURE (AVATAR)
================================================

1) Fetch avatar using Baileys:
- Use:
  await sock.profilePictureUrl(chatId, "image")

2) Rules:
- If user has no photo or privacy blocks → fallback to default avatar (initials)
- Cache avatar (TTL 24h)
- Save in DB:
  - profilePicUrl
  - profilePicUpdatedAt

3) Background execution:
- NEVER fetch avatar directly inside messages.upsert
- Enqueue avatar fetch job
- When avatar is updated:
  - emit socket event:
    "contact_update" → { chatId, profilePicUrl, contactName }

================================================
B) RECEIVE & VIEW MEDIA (IMAGE / PDF / AUDIO)
================================================

1) Detect media types:
- imageMessage → image
- documentMessage + mimetype application/pdf → pdf
- audioMessage → audio

2) Download media (BACKGROUND ONLY):
- Use downloadMediaMessage
- Save to:
  /uploads/<sanitized_chatId>/<messageId>.<ext>
- Generate public URL:
  /uploads/<sanitized_chatId>/<messageId>.<ext>

3) Save in DB (linked to message):
{
  mediaType: "image" | "pdf" | "audio",
  mediaUrl,
  fileName,
  mimetype,
  size
}

4) Front-end rendering:
- Image:
  <img src="mediaUrl" />
- PDF:
  - Card with filename + Open button
  - Optional embedded preview:
    <iframe src="mediaUrl"></iframe>
- Audio:
  - Native player:
    <audio controls src="mediaUrl"></audio>

================================================
C) SEND MEDIA (IMAGE / PDF / AUDIO)
================================================

1) Upload endpoint:
POST /api/upload (multipart/form-data)
- Use multer
- Return:
  { url, fileName, mimetype }

2) Send message endpoint:
POST /api/messages/send
Payload:
{
  chatId,
  type: "text" | "image" | "pdf" | "audio",
  text?,
  mediaUrl?,
  fileName?,
  mimetype?,
  ptt?        // for WhatsApp voice note
}

3) Baileys send rules:
- Text:
  sock.sendMessage(chatId, { text })
- Image:
  sock.sendMessage(chatId, {
    image: { url: mediaUrl },
    caption: finalText
  })
- PDF:
  sock.sendMessage(chatId, {
    document: { url: mediaUrl },
    mimetype: "application/pdf",
    fileName,
    caption: finalText
  })
- Audio:
  sock.sendMessage(chatId, {
    audio: { url: mediaUrl },
    mimetype: "audio/ogg; codecs=opus",
    ptt: true   // voice note
  })
