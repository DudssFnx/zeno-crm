CRITICAL FIX — “DISPOSITIVO VINCULADO” APPEARING IN CHAT
BAILEYS WHATSAPP CRM

PROBLEM:
Inbound and outbound messages are showing the sender name as
“Dispositivo vinculado” instead of the client phone/name.

This happens when messages sent by MY OWN WhatsApp (from another linked device)
are incorrectly treated as contact messages.

================================================
ROOT CAUSE (TO ANALYZE)
================================================

In Baileys:
- Messages sent by me have:
  msg.key.fromMe === true
- These messages DO NOT have pushName
- pushName is undefined
- The code is incorrectly using pushName for sent messages

As a result, the system falls back to:
"Dispositivo vinculado"

THIS IS WRONG.

================================================
MANDATORY RULE (NON-NEGOTIABLE)
================================================

NEVER use pushName for messages where:
msg.key.fromMe === true

================================================

================================================

1) MESSAGE AUTHOR NAME LOGIC

Implement this logic EVERYWHERE (list, chat, database):

IF msg.key.fromMe === true:
  senderName = operator.displayName OR "Você"

IF msg.key.fromMe === false:
  senderName = msg.pushName OR formatted phone number

DO NOT:
- show "Dispositivo vinculado"
- show empty name
- use pushName when fromMe === true

- Always represent the CLIENT

1) Saved contact name
2) Last known pushName from inbound message
3) Formatted phone number

NEVER:
- replace contact name with “Dispositivo vinculado”
- replace contact name based on outbound messages
