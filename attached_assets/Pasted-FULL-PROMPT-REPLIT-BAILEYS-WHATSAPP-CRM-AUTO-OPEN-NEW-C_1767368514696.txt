A) ABSOLUTE RULE: INBOUND MESSAGES MUST CREATE/OPEN CHATS
================================================

On `messages.upsert` (type=notify):
- Get chatId strictly from:
  chatId = msg.key.remoteJid
- Ignore:
  - status@broadcast
- If groups not supported:
  - ignore @g.us

Then:
1) Upsert conversation:
- If conversation with chatId does not exist:
  - create it immediately with:
    chatId
    phone (extract digits)
    contactName = msg.pushName || "Unknown"
    stageId default = "NEW"
    tags default = []
    createdAt / lastMessageAt = now
- If exists:
  - update lastMessageAt
  - update contactName if msg.pushName changed (keep latest)

2) Emit to frontend immediately:
- socket event: "conversation_upserted"
- socket event: "wa_new_message"

3) Mark conversation as “unread”:
- Increment unreadCount for that chatId
- Add “unread badge” in UI
